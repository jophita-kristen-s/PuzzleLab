PSEUDOCODE

The core idea

LANGUAGE-AGNOSTIC
solve(board):
  cell = find_empty_cell(board)
  if cell does not exist:
    return success

  for number in 1..9:
    if number is valid at cell:
      place number at cell
      if solve(board):
        return success
      remove number from cell  ← backtrack

  return failure

This is illustrative pseudocode. The working Sudoku solver is implemented in JavaScript in app.js.
